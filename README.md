# Книжная полка: Telegram-магазин художественной литературы

Минимальный проект: весь код Telegram-бота и Mini App находится в `bot.py`. Каталог, корзина, избранное и заказы хранятся в SQLite.

## Возможности

- Каталог с категориями и страницами; поиск по названию, автору, жанру и описанию.
- Карточка книги, цена, описание и остаток на складе.
- Корзина с изменением количества и проверкой наличия.
- Избранное и история заказов.
- Оформление заказа с телефоном и адресом/самовывозом.
- Современный адаптивный Telegram Mini App: каталог, фильтры, поиск, карточки, корзина и оформление заказа.
- Уведомления администраторам о заказах; управление каталогом, остатками и статусами заказов.
- Один процесс запускает и Telegram long polling, и HTTP-сервер, что удобно для Render.
- Проверка подписи `Telegram.WebApp.initData` на сервере перед созданием заказа.

> В начальном каталоге стоят демонстрационные товары, цены и остатки. Перед настоящими продажами замените их на свои. Оплата картой не подключена; заказ отправляется продавцу для ручного подтверждения.

## 1. Что понадобится

- Python 3.11 или 3.12.
- Токен, который уже выдали в `@BotFather`.
- Telegram ID администратора. Его можно узнать у бота вроде `@userinfobot`.

**Не публикуйте токен бота в GitHub и не вставляйте его в исходный код.** Он задаётся переменной окружения.

## 2. Запуск на Windows

1. Распакуйте архив в папку, например `C:\bookstore-telegram-bot`.
2. Откройте эту папку в Проводнике, щёлкните адресную строку, напишите `powershell` и нажмите Enter.
3. Создайте виртуальное окружение и установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если команда активации заблокирована политикой PowerShell, запустите `cmd` и используйте `.venv\Scripts\activate.bat`.

4. Задайте токен и ID администратора **в этом окне PowerShell**:

```powershell
$env:BOT_TOKEN="ВСТАВЬТЕ_ТОКЕН_ИЗ_BOTFATHER"
$env:ADMIN_IDS="123456789"
python bot.py
```

Поменяйте `123456789` на свой числовой Telegram ID. Для нескольких администраторов используйте список через запятую, например `$env:ADMIN_IDS="123456789,987654321"`.

5. Откройте в браузере `http://127.0.0.1:8000/`. Сайт каталога будет доступен локально. Напишите своему боту в Telegram `/start` и попробуйте каталог/корзину.

Остановка сервера: `Ctrl+C`. После закрытия PowerShell переменные окружения исчезнут, их нужно будет задать повторно.

### Mini App в Telegram при локальном запуске

Telegram требует для Mini App публичный HTTPS-адрес. `http://127.0.0.1:8000/` доступен только на вашем компьютере, поэтому сам по себе не откроется в качестве Telegram Mini App на телефоне. Для проверки используйте HTTPS-туннель, например Cloudflare Tunnel или ngrok, направленный на порт `8000`, а затем в том же терминале задайте публичный адрес:

```powershell
$env:WEBAPP_URL="https://ВАШ-ПУБЛИЧНЫЙ-HTTPS-АДРЕС"
python bot.py
```

URL должен начинаться с `https://`. После этого бот поставит Mini App в кнопку меню и клавиатуру. Для туннеля используйте только доверенный сервис и не публикуйте токен бота.

## 3. Развёртывание через GitHub и Render

1. Создайте новый репозиторий GitHub и загрузите в него файлы `bot.py`, `requirements.txt`, `render.yaml`, `README.md` и `.gitignore`. Не загружайте базу `.sqlite3` и не добавляйте токен в код.
2. В Render выберите **New → Blueprint** и подключите этот GitHub-репозиторий. Render прочитает `render.yaml` и создаст Python Web Service.
3. В настройках/при создании задайте секрет `BOT_TOKEN` (токен от BotFather) и `ADMIN_IDS` (числовой Telegram ID администратора). Запустите deploy.
4. После публикации Render выдаст адрес вида `https://knizhnaya-polka-bot.onrender.com`. Приложение автоматически использует переменную `RENDER_EXTERNAL_URL`, задаёт HTTPS-ссылку Mini App и запускает сервер вместе с ботом. Откройте бота в Telegram, нажмите `/start` и перезапустите чат, если кнопка меню не обновилась.
5. Проверьте адрес `https://ВАШ-АДРЕС.onrender.com/health`: он должен вернуть `{"status":"ok","service":"bookstore"}`.

Если вы создаёте сервис не через Blueprint, укажите:
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python bot.py`
- **Environment:** `BOT_TOKEN`, `ADMIN_IDS`.

### Важное про хранение данных на Render

На бесплатном Render файловая система обычно временная: локальная SQLite-база может потеряться при перезапуске, новом deploy или переносе экземпляра. Для реального магазина обязательно настройте постоянное хранилище: переведите Web Service на тариф с поддержкой Persistent Disk, подключите диск, например к `/var/data`, и задайте `DATABASE_PATH=/var/data/bookstore.sqlite3`. Либо перенесите хранилище на управляемую PostgreSQL-базу. Не полагайтесь на файловую SQLite-базу в бесплатном сервисе для единственной копии заказов.

## 4. Команды администратора

В Telegram используйте команды от аккаунта, ID которого указан в `ADMIN_IDS`:

- `/admin` — подсказка по администрированию.
- `/addbook` — добавление книги. Следуйте инструкции и отправьте строку вида:

```text
Название | Автор | Жанр | Цена в сумах | Количество | Описание | URL обложки или -
```

Пример:

```text
Сад забытых слов | Алия Каримова | Современная проза | 55000 | 8 | Роман о семье и памяти | -
```

- `/setstock ID КОЛИЧЕСТВО` — изменить складской остаток.
- `/delbook ID` — скрыть книгу из каталога (история старых заказов останется).
- `/orders_admin` — последние заказы.
- `/orderstatus ID new|processing|shipped|completed|cancelled` — изменить статус. Пользователь получит уведомление в Telegram.

`ID` книги показывается после её добавления. Начальный демонстрационный каталог использует ID от 1 до 12.

## 5. Настройки и ограничения

- `BOT_TOKEN` — обязателен.
- `ADMIN_IDS` — Telegram ID администраторов через запятую; нужен для команд управления и уведомлений о заказах.
- `WEBAPP_URL` — публичный HTTPS URL Mini App. На Render можно не задавать: приложение использует `RENDER_EXTERNAL_URL`. Локально нужен HTTPS-туннель, чтобы открыть Mini App внутри Telegram.
- `DATABASE_PATH` — путь к SQLite-файлу; по умолчанию `bookstore.sqlite3` рядом с `bot.py`.
- `PORT` — HTTP-порт; на Render выставляется автоматически.

Онлайн-оплата, автоматический расчёт стоимости доставки, интеграция с курьерской службой и юридические документы магазина намеренно не имитируются. Их нужно подключать отдельно под реальные правила торговли.
